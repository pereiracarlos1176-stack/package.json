MTZ para Backup

Mete um tema .mtz dentro de um backup da app Temas do MIUI/HyperOS, para o instalares com Backup e restauro. Tudo é feito neste aparelho: os ficheiros não são enviados para lado nenhum.

PASSO 1Faz um backup modelo no telemóvel

  1. Na app Temas, descarrega e aplica um tema gratuito qualquer da loja.
  2. Vai a Definições → Acerca do telefone → Fazer backup e restaurar → Este dispositivo. No HyperOS o menu pode estar noutro sítio: escreve backup na pesquisa das Definições e escolhe o backup local (no dispositivo), não o da nuvem.
  3. Desmarca tudo e escolhe só a app Temas (em Apps). Faz o backup sem palavra-passe.
  4. No gestor de ficheiros, abre a pasta do backup:
Armazenamento interno/
└── MIUI/backup/AllBackup/
    └── 20261029_153012/
        ├── Temas(com.android.thememanager).bak
        └── descript.xml

Os nomes e o caminho podem variar um pouco conforme a versão. Esta ferramenta troca o tema que está dentro desse backup pelo teu .mtz, mantendo o resto tal como o teu telemóvel o gerou.

PASSO 2Escolhe os ficheiros

.mtzToca para escolher o tema
.bakToca para escolher o .bak do passo 1
.xmlToca para escolher o descript.xml da mesma pasta

PASSO 3Resultado e restauro

Escolhe o tema e o backup modelo para começar.
Como restaurar no telemóvel
  1. Descompacta o ZIP na raiz do armazenamento interno. Fica uma pasta nova dentro de MIUI/backup/AllBackup/.
  2. Abre Fazer backup e restaurar → Este dispositivo, escolhe o backup novo e restaura.
  3. Abre Temas → Perfil → Os meus temas. O tema substitui o que estava no backup modelo; aplica-o daí se não ficar aplicado logo.
